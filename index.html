>>>---------------------------> Arch, aimed at you.

Archer is an Arch Linux based OS built around one idea: everything is swappable. Pick your desktop, kernel and software at install time, then keep shaping it with themes and plugins through a single archer command.

Install

Boot the Arch Linux live ISO, get online, then run one of these. Latest release: …

curlcurl -fsSL https://kvxnomxyz.github.io/archer/install.sh | bash
wgetwget -qO- https://kvxnomxyz.github.io/archer/install.sh | bash

The launcher always pulls the newest release from GitHub. Pin a version with ARCHER_VERSION=v0.1.0 in front of bash. The installer erases the disk you choose.

What you get

  • Guided TUI installer: btrfs or ext4, linux / zen / lts, systemd-boot
  • Desktops: Hyprland, Sway, KDE, GNOME, or none
  • Software bundles: dev, gaming, creator, office, media
  • archer theme set restyles terminal, bar and compositor at once
  • archer plugin add installs plugins: any git repo with a package list and hooks
  • First-boot setup runs once, then removes itself
